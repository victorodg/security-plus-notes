# Security+ Notes — Logging and Monitoring

Tags: #security-plus #logging #siem #monitoring

## Windows Logs

Viewable using the **Windows Event Viewer**.

| Log Type | What It Records |
|---|---|
| **Security Log** | Functions as a security log, audit log, and access log — e.g., user login attempts, file deletion |
| **System Log** | Events related to the operating system — e.g., system power on/off, services starting/stopping, drivers loading or failing |
| **Application Log** | Events generated by applications or programs running on the system |

---

## Linux Logs

Located under **/var/log/**.

- **/var/log/syslog** and **/var/log/messages** — general system messages related to mail, the kernel, and other subsystems
- **/var/log/secure** — related to authentication and authorization of user sessions (login attempts, sudo usage, etc.)

---

## Network Logs

Record traffic passing through the network.

- **Firewall Logs** — record what traffic was allowed to enter/leave the network and what traffic was blocked
- **IDS/IPS Logs** — monitor the network for malicious activity
- **Packet Captures** — protocol analyzers (sniffers) capture raw network traffic, allowing administrators to view and analyze individual packets

---

## Application Logs

Common fields recorded (e.g., in web server logs):

- **host** — IP or hostname of the client
- **user-identifier** — name of the user requesting the page
- **authuser** — the user's logon name used in the request
- **date** — date and time of the request
- **request** — the actual request line sent by the client
- **status** — the HTTP status code returned to the client
- **bytes** — the length of the reply

---

## Metadata

Data that provides information *about* other data — e.g., file creation date, author, GPS coordinates on a photo, email headers. Often overlooked but can be forensically valuable.

## Centralized Logging and Monitoring

### SIEM Systems (Security Information and Event Management)

Provides a centralized solution for collecting, analyzing, and managing data from systems, applications, and infrastructure devices. Combines two functions:

- **SEM (Security Event Management)** — real-time monitoring, analysis, and notification of security events
- **SIM (Security Information Management)** — long-term storage of data, plus methods to analyze that data for trends or generate reports

SIEM systems use scripts to automate monitoring and reporting.

### Core SIEM Components

- **Log collectors** — the SIEM collects log data from devices throughout the network
- **Data inputs** — logs from various sources: firewalls, routers, network intrusion detection/prevention systems, etc.
- **Log aggregation** — combining several dissimilar log formats into a single, consistent format
- **Correlation engine** — a software component that analyzes event log data from various systems, aggregating data to find common attributes, then applying analytic tools to detect patterns of potential security threats
- **Automated reports** — scheduled or triggered reporting on system activity
- **User behavior analysis (UBA)** — watches critical files to track who accessed them, what they did, and how frequently — looking for abnormal patterns of activity
- **Security alerts** — continuous monitoring with notifications of suspicious events
- **Automated triggers** — cause an action in response to a predefined number of repeated events (e.g., X failed login attempts in Y minutes)
- **Time synchronization** — ensures logs from different systems can be correlated accurately by timestamp
- **Archiving** — long-term storage of log data for compliance and later investigation

### SIEM Dashboards

Give administrators a visual view of meaningful activity:

- **Sensors** — collect logs from devices
- **Alerts** — surfaced notifications of suspicious activity
- **Correlation** — relationships identified between events
- **Trends** — patterns over time

---

## Syslog

A standard protocol that specifies a general log entry format and defines how log entries are transported between systems. It's the common language that lets different devices and systems send logs to a centralized collector (like a SIEM) in a consistent way.

---

## Quick Recap
- **Windows**: Security / System / Application logs, viewed via Event Viewer
- **Linux**: /var/log/syslog, /var/log/secure
- **Network**: Firewall, IDS/IPS, packet captures
- **SIEM** = SEM (real-time) + SIM (long-term storage/analysis), built from collectors, correlation engine, UBA, alerts, and dashboards
- **Syslog** = the standard transport protocol that feeds logs into centralized systems like a SIEM
